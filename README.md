🍽️ Odin Recipes

Este proyecto es parte del curso Foundations de The Odin Project y consiste en la creación de un sitio web básico de recetas utilizando solo HTML.

📌 Descripción

El objetivo de este proyecto es practicar los fundamentos de HTML construyendo una página web sencilla que contenga:

Una página principal (index.html)
Enlaces a varias recetas
Páginas individuales para cada receta

Este proyecto no se enfoca en el diseño visual, sino en fortalecer las bases de HTML. Más adelante se mejorará con CSS.

🛠️ Tecnologías utilizadas
HTML5
Git
GitHub

📂 Estructura del proyecto
odin-recipes/
│── index.html
│── recipes/
│   ├── receta1.html
│   ├── receta2.html
│   └── receta3.html

🎯 Objetivos de aprendizaje
Comprender la estructura básica de HTML
Usar correctamente:
Listas (ul, ol)
Enlaces (a)
Imágenes (img)
Organizar archivos en carpetas
Utilizar Git y GitHub para versionado

🧠 Lo que aprendí
Cómo estructurar una página web desde cero
Cómo enlazar múltiples páginas
Buenas prácticas básicas de HTML
Flujo básico de trabajo con Git
